A LITTLE FOREVER, BETU — GitHub Pages site

1. Extract this ZIP.
2. Create a new GitHub repository (for example: betu-forever).
3. Upload index.html, style.css, script.js and the assets folder to the repository root.
4. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Open the Pages URL GitHub gives you.
